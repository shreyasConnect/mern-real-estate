# 🏡 Estate Navigator

Estate Navigator is a full-stack real estate web application that enables users to explore property listings, communicate with property owners in real-time, and manage accounts securely. The platform focuses on providing a smooth property discovery experience through advanced search filters and secure authentication mechanisms.

---

## 🚀 Features

- 🔐 Secure user authentication using **JWT**
- 🔑 **Google OAuth login** integration using Firebase
- 💬 **Real-time chat system** between users using Socket.IO
- 🏠 Property listing and browsing
- 🔎 Advanced **property search and filtering**
- ⚡ Optimized backend queries for efficient data retrieval
- 👤 User account management
